Aegis Red

Open-source assurance for AI applications and agents. Authorized tests. Pass or Fail. No exploit cookbook.

The problem

AI applications and agents can leak secrets, invent facts, honor a fake policy, or call tools they were never granted. Teams need an authorized way to prove those failures do not happen — without publishing jailbreak recipes.

Aegis Red is a harness: you describe intents (seeds) and oracles. It talks to a system under test, records the transcript, and scores Pass or Fail with examiner-grade evidence.

Who this is for

Individual contributor

Add a seed or policy probe in YAML. Good first issues are listed under Contribute.

UAT / QA

Stay in Try now. Add two tests in plain language, run them, download a Pass/Fail sheet.

Engineer

Use the live HTTP demo SUT, then point sut.kind at your own agent plugin.

How we test AI (coverage)

Core pack covers Tech / AI safety. Banking is an optional domain pack. Community seeds live in the seed store.

Mock test without leaving the portal

Fill two examples, save, then run. You can also write your own on Try now.

Few-click setup

Clone this repository, run one script, open the portal. The script starts the portal and a live demo agent together.
