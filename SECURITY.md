# Security

Aegis Red is an **authorized assurance harness**. It is not a place to publish working attacks.

## Report a vulnerability in this project

1. Do **not** open a public GitHub issue with an exploit, jailbreak payload, or bypass recipe.
2. Use **GitHub → Security → Advisories → New draft security advisory** on this repository (enable private reporting in repo settings if it is off).
3. Describe the **intent** and the **affected surface** (portal, demo SUT, adapter, oracle). Do not attach working payloads.

Maintainers: turn on “Private vulnerability reporting” under Settings → Code security.

## What belongs in public issues

- Broken setup on Mac or Windows
- Portal bugs, Pass/Fail scoring mistakes
- Missing oracles for an already-described intent
- Documentation that is unclear for UAT or contributors

## What does not belong

- Jailbreak strings
- Tool-call sequences that bypass policy
- Production credentials, customer data, or live evidence dumps
