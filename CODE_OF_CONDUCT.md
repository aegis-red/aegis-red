# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our pledge

We pledge to make participation a harassment-free experience for everyone.

## Our standards

- Be respectful. Critique ideas, not people.
- No jailbreak payloads, exploit dumps, or instructions that turn this repo into an attack cookbook.
- Do not share customer data, production secrets, or live credentials in issues or PRs.

## Enforcement

Project maintainers may remove comments, close issues, or block contributors who violate this code. Report conduct issues privately to the maintainers.

This Code of Conduct is adapted from the Contributor Covenant, version 2.1.
